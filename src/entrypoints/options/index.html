Turbobulls Connector

Prices from your own market-data provider, with your own API key, for Turbobulls.

How it works

  • Paste the API key of the provider you pay for below. It stays in this browser, on this device.
  • In Turbobulls, open a custom asset and choose From my data provider.
  • Turbobulls asks this extension for prices; the extension asks your provider and passes back only the prices.
  • Turbobulls never sees your key. This extension cannot read any web page, Turbobulls included.
